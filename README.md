# AVA Studio - Professional Creative & Photo Studio Suite (v2.0 Fixed)

![AVA Studio Banner](https://images.unsplash.com/photo-1618005182384-a83a8bd57fbe?w=1200&auto=format&fit=crop&q=80)

تطبيق **AVA Studio** هو استوديو تصميم ومحرر صور سينمائي متقدم وعالي الأداء، يدعم العمل بكفاءة كـ:
1. **تطبيق ويب محلي متكامل (100% Offline Compatible)** جاهز للتحويل الفوري إلى APK بدون أي أخطاء.
2. **تطبيق Android Native (Kotlin + Jetpack Compose + Room Database)** مجهز بأعلى معايير بنية وتصميم Material Design 3.

---

## 🛠️ 1. حل مشكلة «محتوى التطبيق مفقود» جذريًا

### سبب المشكلة الحقيقي:
عندما تقوم بتحميل المشروع من GitHub عبر زر **"Download ZIP"**، يقوم GitHub بإنشاء مجلد رئيسي داخل ملف الضغط يحمل اسم المستودع والفرع (مثال: `AVA-App-Fixed-v2-main/`).
وبناءً على ذلك، يصبح ملف `index.html` موجودًا داخل المسار الفرعي:
`AVA-App-Fixed-v2-main/index.html` بدلاً من أن يكون في الجذر المباشر للأرشيف `/index.html`.

عند رفع ملف الـ ZIP هذا إلى أدوات وتطبيقات تحويل المواقع لـ APK الخارجية (مثل Website 2 APK أو صانع التطبيقات):
تقوم الأداة بالبحث عن `index.html` في **الجذر المباشر فقط** للأرشيف. وعندما لا تجده، تقوم بتوليد APK بدون ملفات الواجهة الأساسية، مما يتسبب في ظهور الرسالة:
> **«محتوى التطبيق مفقود — تعذر تحميل الملفات المضمنة في هذا التطبيق. يرجى إعادة بناء APK باستخدام ملف ZIP يوجد فيه index.html في الجذر».**

---

### الحلول الجاهزة في هذا الإصدار:

#### الخيار (أ) - استخدام ملف الـ ZIP الجاهز مباشرة:
تم توفير ملف جاهز باسم:
```
dist/ava-apk-ready.zip
```
يحتوي هذا الملف في **الجذر المباشر** على:
- `index.html`
- `css/style.css`
- `js/app.js`

يمكنك أخذ هذا الملف مباشرة ورفعه إلى تطبيق التغليف الخارجي وسيعمل فوراً دون أي خطأ.

#### الخيار (ب) - إنشاء ملف ZIP بنفسك بالطريقة الصحيحة:
1. افتح مجلد المشروع.
2. حدد الملفات التالية معًا:
   - `index.html`
   - مجلد `css`
   - مجلد `js`
3. اضغط بالزر الأيمن واختر **"إرسال إلى ملف مضغوط (Compress to ZIP)"** (أو عبر تطبيق إدارة الملفات في الهاتف).
4. **تنبيه:** لا تقم بضغط المجلد الخارجي للمشروع، بل اضغط الملفات الداخلية مباشرة بحيث يظهر `index.html` فور فتح ملف الـ ZIP.

#### الخيار (ج) - استخدام سكربت الضغط التلقائي:
قم بتشغيل السكربت البسيط:
```bash
python3 package_for_apk.py
```
وسيقوم بإنشاء `dist/ava-apk-ready.zip` فوراً والتحقق من وجود `index.html` في الجذر.

## 🔐 2. نظام تسجيل الدخول والمصادقة المتكامل

تم بناء نظام مصادقة احترافي وآمن متوافق مع نسخة الويب ونسخة أندرويد الأصلية:

### الميزات الأمنية والوظيفية:
1. **إنشاء حساب جديد (Register):**
   - الاسم الظاهر (`Display Name`).
   - اسم مستخدم فريد (`@username`) مع فحص ومنع التكرار.
   - البريد الإلكتروني مع التحقق من الصيغة والتفرد.
   - كلمة مرور قوية مع تشفير **Salted SHA-256** وحفظ Salt عشوائي فريد لكل حساب.
   - الموافقة على شروط الاستخدام والخصوصية.
2. **تأكيد البريد الإلكتروني (Email Verification):**
   - رمز تحقق سداسي (6 أرقام) يتم إنشاؤه مع كل حساب جديد لمنع الحسابات الوهمية.
   - واجهة إدخال من 6 خانات منفصلة مع انتقال تلقائي للتركيز، وإمكانية إعادة إرسال الرمز.
3. **تسجيل الدخول وإبقاء الجلسة (Login & Persistent Session):**
   - تسجيل الدخول بالبريد وكلمة المرور المشفرة.
   - إبقاء الجلسة نشطة ومحفوظة حتى بعد إغلاق التطبيق وإعادة فتحه عبر `SessionManager` ورمز الجلسة الفريد.
4. **استعادة كلمة المرور (Forgot Password):**
   - إرسال رمز استعادة سداسي وتأكيده ثم إدخال كلمة المرور الجديدة وتحديث التجزئة.
5. **الملف الشخصي المستقل (User Profile):**
   - شاشة ملف شخصي مخصصة لكل مستخدم.
   - تعديل الاسم والنبذة التعريفية.
   - عرض رصيد العملات والمشاريع والمتابعين.
6. **عزل البيانات التام (Data Isolation):**
   - كل مستخدم لديه معرض مشاريع خاص به، ولا يمكن لمستخدم آخر رؤية أو حذف أعمال غيره.
7. **حساب المؤسس المعتمد (Founder Account):**
   - حساب المؤسس **Ayham** (`user_ayham_creator` / `@ayham_creative`) معتمد ومحمي بصلاحية `isFounder: true`.
   - يظهر بشارة ذهبية مميزة في الواجهة، ولا يمكن لأي مستخدم عادي منح نفسه صفة المؤسس عند التسجيل.
8. **إدارة الحساب والأمان (Settings):**
   - تغيير كلمة المرور بعد التحقق من كلمة المرور الحالية.
   - تسجيل الخروج من الجلسة.
   - خيار **حذف الحساب نهائيًا** مع مسح كافة الأعمال المحفوظة بضغطة زر وتأكيد أمني.

## 🎨 3. ميزات استوديو AVA الإبداعية

- **استوديو الصور الشخصية:** تحسين تلقائي، رتوش للبشرة، إضاءة استوديو، فلاتر سينمائية نقية، أبيض وأسود درامي، تظليل الحواف، وزر مقارنة (قبل / بعد).
- **استوديو الإعلانات:** محرر بوسترات ترويجية مع تخصيص العنوان والنص والشارة وزر الإجراء وتوليد تصاميم عالية الدقة.
- **مصمم القصص 9:16:** قوالب رأسية مخصصة لإنستغرام وتيك توك.
- **تصدير عالي الدقة:** إمكانية تنزيل وحفظ الأعمال بصيغة JPEG عالية الجودة محلياً في جهازك.
- **ثنائي اللغة:** دعم كامل للعربية (مع اتجاه RTL) والإنجليزية (LTR).

## 🚀 4. خطوات رفع المشروع كإصدار جديد على GitHub (AVA-App-Fixed-v2)

إذا أردت رفع المشروع إلى حسابك على GitHub في مستودع جديد مستقل:

```bash

git init
git add .
git commit -m "feat: complete AVA Studio v2 with real auth and root web packaging"

# 2. تغيير اسم الفرع إلى main
git branch -M main

# 3. ربط المستودع الجديد بحسابك على GitHub (استبدل YOUR_USERNAME باسم حسابك)
git remote add origin https://github.com/YOUR_USERNAME/AVA-App-Fixed-v2.git

# 4. رفع الملفات إلى المستودع
git push -u origin main
```

## 🤖 5. الفحص والتحقق التلقائي (GitHub Actions)

تم إعداد ملف العمل التلقائي:
`.github/workflows/verify-and-package.yml`
ويقوم تلقائياً عند أي `push` بالآتي:
1. التأكد من وجود `index.html` في الجذر.
2. التحقق من سلامة كافة ملفات الـ CSS والـ JS.
3. بناء نسخة الـ APK الأصلية من كود Android بواسطة Gradle.
4. تجهيز ملف `ava-apk-ready.zip` ورفعه كـ Artifact قابل للتنزيل فورًا للاستخدام مع المحولات الخارجية.
